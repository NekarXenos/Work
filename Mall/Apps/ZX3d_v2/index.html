ZX SPECTRUM 3D

A Sinclair machine you can walk around inside.

The screen is 255×175 pixels extruded 255 blocks deep. Every coordinate takes a third value. Every pixel may be any of the 16 Spectrum colours — there is no attribute clash.

Walk to any of the four terminals at the centre of each edge and type ZX BASIC on the +2 keyboard. SCREEN 4 sends your drawing into the world itself.

ZX SPECTRUM 3D — Operating Manual

Save builds for your game: press F4 or click SAVE 3D. Save the whole screen as scenery, or crop a character / sprite (optionally within a coordinate box). Download a .zx3d file and import it here later. Load scenery with LOAD "name" SCREEN$, or a character with LOAD "name" SPRITE 1, then PUT 1,x,y,z and MOVE 1,x,y,z. Colours and materials are preserved. The save panel shows an example for your asset.

1. Draw your first line

Walk to a terminal, press E, then type:

10 SCREEN 4
20 CLS
30 INK 6
40 PLOT 20,20,200
50 DRAW 200,120,-150
RUN

PLOT x,y,z lights one voxel. DRAW dx,dy,dz draws a line relative to the last point — exactly like Sinclair BASIC, with a third value for depth. Use DRAW TO x,y,z for absolute.

Coordinates: x 0–254 left→right, y 0–174 bottom→top, z 0–254 front→back (into the screen). Origin is bottom-front-left, as PLOT always was.

Now press Esc, walk into the screen, and look at what you made.

2. The 3D screen

SCREEN 0 — output to the terminal CRT (32×24 text).
SCREEN 4 — output to the voxel world (31×21 text).

SCREEN 4 is this machine's answer to the SAM Coupé's MODE 3: the same idea, one dimension further on. Modes 1–3 are reserved for flat screens, so the solid display took the next free number.

All 16 colours are available on every single pixel. There is no attribute cell and therefore no clash — the Coupé trick, in three dimensions.

4. Animated voxel sprites

Define a sprite as a stack of coloured layers, then move it:

10 SPRITE 1,3,3,1,2
20 SDATA 1,0,0,".6."
25 SDATA 1,0,1,"666"
30 SDATA 1,0,2,".6."
40 SDATA 1,1,0,"6.6"
50 SDATA 1,1,1,".6."
60 SDATA 1,1,2,"6.6"
70 SCREEN 4: CLS
75 LET f=0
80 FOR x=0 TO 240
85 LET f=1-f
90 MOVE 1,x,80,128,f
95 PAUSE 2
100 NEXT x
110 UNPUT 1

SDATA n,frame,row,a$ fills one row of one frame; each character is a hex colour digit 0–F, or . for transparent. Layers deeper than the first are given with SDATA n,frame,row,a$,layer.

PUT n,x,y,z,f stamps a frame and remembers what was underneath. UNPUT n puts the background back. MOVE n,x,y,z,f does both — that is your animation loop.

Rather than typing it: LOAD "SPRITE" is the listing above, LOAD "LINE" is the first example, and LOAD "DEMO" flies a two-frame sprite on a Lissajous path through the display. RUN any of them.

There is no MOD — Sinclair never had one. Write a-INT (a/b)*b.

5. Tape, saving and loading

SAVE "name"program to virtual tape
SAVE "name" SCREEN$the whole voxel world
LOAD "name"load it back
CATlist the tape
ERASE "name"wipe a block

The TAPE panel (T) exports the tape as a real .tap file and imports .tap, .tzx, .sna and .z80. Loading one of those starts the built-in Z80 and runs it as a genuine 48K Spectrum on the terminal CRT. Turn on PROJECT TO 3D and the emulated display is rebuilt as voxels, one block deep, inside the world.

For full compatibility drop your own 16 KB 48.rom into the tape panel. Without one, a compact substitute ROM runs most snapshots and simple .tap loaders.

Inside the screen volume you move like Minecraft — blocky gravity, auto-step, dig and build. Outside it you get ordinary first-person movement: faster, longer stride, no voxels in your way.

7. The keyboard

The terminal carries a +2 keyboard with 1/8 m keys. Click a key, or use your own keyboard.

Hold Shift (CAPS SHIFT) or Ctrl (SYMBOL SHIFT) and every key cap re-letters itself in real time to show what it will produce. Hovering a key does the same for that one key and shows the result in the toolbar before you commit to it.

TYPING: SPECTRUM is authentic — one keypress gives you a whole keyword, exactly as 1982 intended. TYPING: AUTO lets you type plot 20,20,200 as ordinary text and recognises the keywords for you as you go. Switch with the toolbar button or F2.

8. Memory

This machine has no fixed RAM. It measures the computer it is running on and takes a share of it; the gauge at the top left shows the budget and what is left. PRINT MEM reports free bytes to BASIC, and CLEAR n still lowers RAMTOP if you want a smaller machine.
